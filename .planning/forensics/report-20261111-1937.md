## 3. Detected Anomalies & Root Cause Analysis

### Anomaly 1: Host C++20 Compiler Staleness
- **Evidence:** Host had MinGW GCC 6.3.0 (from 2016, 32-bit), lacking `<filesystem>` and `std::clamp`.
- **Root Cause:** Default Windows environment path contained legacy MinGW.
- **Remediation:** Isolated runtime in `.venv` with native Qt 6.12 (`PySide6-Essentials`) and CMake scripts configured for modern MSVC/Ninja toolchains.

### Anomaly 2: Terminal Charset Encoding Mismatch
- **Evidence:** `tests/test_runner.py` threw `UnicodeEncodeError: 'charmap' codec can't encode character '\u2713'`.
- **Root Cause:** Windows command prompt uses legacy code page cp1252.
- **Remediation:** Replaced unicode checkmarks with standard ASCII `[OK]`.

### Anomaly 3: QML Singleton Resolution & Native Style Lock
- **Evidence:** Initial QML load produced warnings: `Unable to assign [undefined] to QColor/int` and `Current style does not support customization`.
- **Root Cause:** Missing `ui/qmldir` registering `GeistTheme.qml` as a singleton; Qt 6 default Windows style rejecting custom `Button.contentItem` delegates.
- **Remediation:** Created `ui/qmldir` with `singleton GeistTheme 1.0 GeistTheme.qml`, added `engine.addImportPath(ui_dir)`, and enforced `QQuickStyle.setStyle("Basic")`.

### Anomaly 4: Display Scaling (High-DPI) & Taskbar Clipping
- **Evidence:** User could not see window on 125% DPI display (1536x912 usable area) when hardcoded to 1280x820.
- **Root Cause:** Fixed window bounds exceeded vertical display limit after 1.25 scaling.
- **Remediation:** Updated `ui/MainWindow.qml` with dynamic bounds: `Math.min(1160, Screen.width - 60)` and `Math.min(720, Screen.height - 80)`.

### Anomaly 5: Missing Remote GitHub Origin
- **Evidence:** `git remote -v` returned empty; `gh` command not found in PATH.
- **Root Cause:** Local git initialized without remote binding.
- **Remediation:** Created automated one-click push script `scripts/deploy_github.ps1` and comprehensive `docs/DEPLOYMENT_GUIDE.md`.
