## [1.0.0] - 2026-11-11
### Added
- **V200 Broadband Pipeline**: Sustained 22–24 MB/s throughput optimization with real-time Bottleneck Attribution across 5 layers.
- **VSE-X Swarm Intelligence**: Dynamic Peer Utility Scoring (PUS) and BDP-based request queue scheduling.
- **V-FORCE & Direct Piece Coalescing Cache**: 3 performance profiles (Balanced, Turbo, Max) with 4MB–16MB RAM piece assembly cutting SSD write amplification by up to 90%.
- **User-Controlled Thermal Guardian**: WMI CPU temperature monitoring with high-visibility Amber warnings (80°C–94°C) without forced speed cuts, reserving emergency Red alerts for critical peaks (>= 95°C).
- **V-SHIELD Security Architecture**: Zero-tolerance path traversal sanitization, Windows Defender / AMSI malware scanning, zero automatic binary execution, and Network Lock kill-switch.
- **Vercel Geist Design System**: 12 responsive production QML views in dark and light modes with 1px hairline borders and Geist typography.
- **Open Source Governance**: Full GPL-3.0 compliance, SBOM generation, and comprehensive 75-question engineering evaluation (`docs/ENGINEERING_QA.md`).
