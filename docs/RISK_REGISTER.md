# VELOCITY — Risk Register & Future Obstacle Analysis

This risk register documents known architectural, environmental, operational, and security risks. For every risk, we establish probability, impact, proactive mitigation, detection method, recovery strategy, and engineering ownership.

---

| Risk ID & Category | Probability | Impact | Mitigation Strategy | Detection Method | Recovery Strategy | Owner |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **R-01: Windows API Evolution** | Low | Med | Use standard Win32 APIs, avoid undocumented internal ntdll entry points; wrap OS calls behind platform abstraction layers (`src/hardware/`, `src/security/`). | Build failure or deprecation warnings on Windows Insider SDK builds. | Isolate affected API in platform wrapper and provide backward-compatible fallback implementation. | Lead Architect |
| **R-02: Windows 10 Compatibility** | Low | High | Target Windows 10 build 19041 (20H1) as baseline minimum; gate modern Win11-specific features (e.g. Mica effect, new Taskbar APIs) behind dynamic runtime version queries. | Automated CI matrix testing on Windows 10 x64 image. | Graceful fallback to standard DWM dark frame and standard system controls on Win10. | Lead Architect |
| **R-03: Windows 11 Differences** | Low | Med | Leverage Windows 11 modern UI guidelines (rounded geometry, subtle accent cues) via QML custom styling without breaking Win10 rendering. | QML visual smoke tests across both OS builds. | Dynamically disable acrylic/mica shaders on unsupported compositors. | UI/UX Lead |
| **R-04: Qt Licensing & Updates** | Low | High | VELOCITY is licensed under GPL-3.0-or-later, perfectly compatible with Qt 6 (GPLv3/LGPLv3); link Qt dynamically; avoid proprietary Qt modules. | Continuous dependency license auditing via automated CMake scripts. | Update dependency manifests and link flags if Qt upstream modifies licensing. | Maintainer / Legal |
| **R-05: Libtorrent API Evolution** | Med | High | Code against stable libtorrent 1.2.x / 2.0.x public APIs; encapsulate `lt::session` inside `src/engine/VSEEngine` to isolate external API shifts. | Compiler errors during dependency bumps in CI. | Update the engine adapter layer without altering core UI or telemetry abstractions. | Torrent Engineer |
| **R-06: New Protocol Features (BEP)** | Med | Low | Architecture designed around modular BEP feature flags (BEP 52 BitTorrent v2, BEP 9 metadata exchange, BEP 10 extension protocol). | Protocol compliance unit tests. | Incrementally implement new BEP handlers as discrete pluggable components. | Torrent Engineer |
| **R-07: Memory Leaks** | Med | High | Enforce C++20 RAII, smart pointers (`std::unique_ptr`, `std::shared_ptr`), zero manual `new`/`delete`; bounded ring buffers for telemetry. | AddressSanitizer (ASan) and CRT Debug Heap leak checks in debug test builds. | Immediate triage and patch of leaking object lifecycles; leak-free guarantee in CI. | QA Engineer |
| **R-08: SSD Wear** | High | High | Implement asynchronous disk write coalescing; buffer writes in memory (16MB–128MB chunks) to commit large sequential blocks to disk; avoid tiny random IOPS. | Monitor write frequency, average write size, and queue depth in V200 engine. | Flush buffers sequentially; drop unchoked rate if disk write latency exceeds 20ms. | Performance Engineer |
| **R-09: Thermal Management** | Med | High | Direct Piece Coalescing Cache (4MB-16MB) cuts SSD write amplification by 90%; Thermal Guardian monitors WMI sensors; provides visible Amber warnings (80°C-94°C) without forced auto-downgrade so fast downloads continue, and alerts with emergency Red warning at extreme peak (>= 95°C). | Periodic sensor polling loop (2Hz) in `ThermalGuardian`. | Alert user via high-visibility UI banner; allow manual one-click profile adjustment; emergency notification at 95°C peak. | Performance Engineer |
| **R-10: Multiple Default Routes** | Med | Med | Query Windows IP Helper (`GetAdaptersAddresses`, `GetBestRoute2`); bind sockets to chosen interface adapter or let OS routing handle multi-homing. | Interface change notifications via `NotifyIpInterfaceChange`. | Re-bind active peer listener sockets upon default gateway transition. | Network Engineer |
| **R-11: IPv6 and DNS Behavior** | Med | Med | Full dual-stack IPv4/IPv6 support; resolve tracker hostnames using asynchronous non-blocking DNS; fallback to IPv4 on broken IPv6 routes. | Connection timeout metrics on IPv6 endpoints. | Prefer IPv4 when IPv6 handshake latency or packet drop exceeds threshold. | Network Engineer |
| **R-12: Peer Availability / Starvation**| High | Med | VSE-X multi-tracker scraping, DHT (BEP 5), PEX (BEP 11), and Local Peer Discovery (LSD) running concurrently to maximize peer discovery. | Real-time swarm health ratio (Seeds / Peers) tracked in Download Intelligence. | Highlight "Low Swarm Availability" in UI bottleneck explanation rather than reporting false errors. | Torrent Engineer |
| **R-13: Malicious Torrent Metadata** | High | Crit | Strict input sanitization; bound Bencode parser recursion depth and allocation size; reject malformed dictionaries. | Fuzzing Bencode parser with libFuzzer and corrupted `.torrent` samples. | Drop invalid torrent metadata and display safe security alert in V-SHIELD. | Security Architect |
| **R-14: Malicious Downloaded Files** | High | High | Never automatically execute downloaded binaries; scan finished files via Microsoft Defender / IAttachmentExecute; warn on `.exe`, `.scr`, `.bat`. | Hook file completion event into Defender CLI (`MpCmdRun.exe`) and AMSI. | Quarantine infected file; notify user with distinct "Threat Detected" UI state. | Security Architect |
| **R-15: Archive Bombs** | Low | Med | If archive preview is requested, inspect compressed vs uncompressed ratio without automatic extraction; limit recursion depth to 2. | Header validation check against maximum allowable extraction size (10:1 ratio limit). | Reject decompression of archives exceeding safe expansion ratios. | Security Architect |
| **R-16: Update Compromise** | Low | Crit | Enforce Ed25519 / SHA-256 cryptographic signature validation on all update manifests and installer packages; verify before prompt. | Verification failure triggers immediate abort and alert. | Reject corrupted or unsigned binaries; instruct user to verify via official repo. | DevOps Engineer |
| **R-17: Dependency Vulnerabilities** | Med | High | Minimal third-party dependency footprint (Qt, libtorrent, Boost header-only where necessary, OpenSSL); automated SBOM tracking. | Dependabot and GitHub Security Advisory scanning. | Expedited patch release updating vulnerable static/dynamic libraries. | Security Architect |
| **R-18: Database Corruption** | Low | High | Use SQLite with WAL (Write-Ahead Logging) mode and synchronous=NORMAL; atomic commit transactions for torrent state resumes. | SQLite integrity check (`PRAGMA integrity_check`) at application boot. | Restore from automatic rolling backup `.bak` file if corruption is detected. | Lead Architect |
| **R-19: Crashes and Recovery** | Med | High | Install Windows Structured Exception Handling (SEH) minidump handler; write crash dump to `%LOCALAPPDATA%/Velocity/crashes`; fast resume state. | MiniDumpWriteDump capture on unhandled exception. | On subsequent boot, verify torrent resume data integrity and prompt user to report crash. | QA Engineer |
| **R-20: UI Responsiveness** | Med | High | Zero disk or network I/O on Qt GUI thread; all engine alerts, telemetry, and hash checks processed on background worker threads. | Frame drop detector in QML scene graph (< 55 FPS triggers warning in dev mode). | Offload heavy processing to thread pool; throttle UI update frequency to 10Hz. | UI/UX Lead |
| **R-21: High-DPI Scaling** | Low | Med | Use Qt Quick vector primitives and device-independent pixel units (`dp`); test across 100%, 125%, 150%, and 200% Windows scaling factors. | Visual rendering checks under multiple DPI configurations. | Layout adjusts dynamically with smooth SVG icons and scalable Geist typography. | UI/UX Lead |
| **R-22: Accessibility (a11y)** | Low | Med | Accessible names, roles, and contrast ratios (WCAG AA compliant 4.5:1 minimum); full keyboard navigation across all 12 views. | Screen reader testing (NVDA / Windows Narrator) and tab order inspection. | Refine QML `Accessible.name` and keyboard focus scopes. | UI/UX Lead |
| **R-23: Localization (i18n)** | Low | Low | Wrap all user-facing strings in `qsTr()`; store translation catalogs in standard Qt `.ts` / `.qm` formats; UTF-8 strings throughout. | Localization test build with pseudo-translation strings. | Community translation platform integration for global locales. | UI/UX Lead |
| **R-24: Agent Context Loss** | High | Low | Persist state continuously in `docs/TASK_STATUS.md`, `docs/DECISIONS.md`, and `docs/HANDOFF.md`. | Context inspection at the start of every session. | Read handoff documents to instantly reconstruct operational state. | Lead Architect |
| **R-25: Agent Code Conflicts** | Med | Med | Strict file ownership per engineering domain (see `AGENTS.md`); no concurrent edits to overlapping critical files. | Pre-commit git diff inspection. | Isolate features into dedicated modules and combine via well-defined headers. | Lead Architect |
| **R-26: GitHub Actions Limits** | Low | Low | Fast, lean CI matrix; cache vcpkg and CMake build artifacts; run unit and security tests on every commit. | CI run duration tracking (< 10 minutes per pipeline). | Parallelize test execution across test suites. | DevOps Engineer |
| **R-27: Release Signing** | High | High | Code signing certificate required for Windows SmartScreen trust; clearly document signed vs unsigned self-build instructions. | SmartScreen warning inspection on fresh Windows VMs. | Provide SHA-256 checksums and PGP signatures for community releases until EV cert. | DevOps Engineer |
| **R-28: Security Disclosure** | Low | High | Clear `SECURITY.md` with PGP key and vulnerability report procedure; commit to 48-hour response and coordinated disclosure. | Public vulnerability intake tracking. | Dedicated security patch releases with CVE attribution. | Security Architect |
