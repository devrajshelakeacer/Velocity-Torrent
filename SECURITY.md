## Reporting a Vulnerability
The VELOCITY engineering team takes security vulnerabilities seriously. If you discover a security vulnerability, **please do not disclose it publicly via GitHub Issues**.

Instead, report it via:
1. **GitHub Private Vulnerability Reporting**: Navigate to the `Security` tab of our GitHub repository and select `Report a vulnerability`.
2. **Encrypted Security Email**: Email `security@velocity-torrent.org` with detailed reproduction steps and an affected component trace.

### Response Timeline & SLA
- **Initial Response**: Within 48 hours.
- **Triage & Reproduction**: Within 5 business days.
- **Remediation & Patch**: Target within 14 business days for Critical / High severity findings.
- **Coordinated Disclosure**: CVE assignment and public release notes published in `SECURITY_ADVISORIES.md` once patched binaries are deployed.
